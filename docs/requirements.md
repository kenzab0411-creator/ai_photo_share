# 写真共有アプリ 要件定義

## 1. アプリの概要

友人同士で、旅行や日常の写真を共有するための小さな写真共有アプリです。
ユーザーはログイン後、写真1枚と短いキャプションを投稿できます。投稿は一覧で写真を中心に表示し、ほかのユーザーは投稿にいいねやコメントを付けられます。

投稿ごとに公開・非公開を選択できます。公開投稿はログインしている全ユーザーが閲覧でき、非公開投稿は投稿者本人だけが閲覧できます。

対象技術は Flask と Peewee です。最初の版では、写真ファイルをアプリ内の専用フォルダに保存します。

## 2. 想定ユーザー

- 友人同士で写真を見せ合いたい人
- 旅行や日常の写真に短いひとことを添えて共有したい人
- ユーザー名とパスワードで登録・ログインできる人

## 3. 必須機能

実装しやすいよう、次の順序で小さく作成します。

### 3.1 ユーザー登録

- ユーザー名とパスワードを入力して登録できる
- 同じユーザー名では登録できない
- パスワードは平文でデータベースに保存しない
- 登録後はログイン画面へ移動できる

### 3.2 ログイン・ログアウト

- 登録済みのユーザー名とパスワードでログインできる
- ログイン中のユーザーが分かる状態をセッションで保持する
- ログアウトできる
- 投稿、いいね、コメントの操作はログインユーザーだけが行える

### 3.3 写真投稿

- ログインユーザーは写真を1枚選んで投稿できる
- 短いキャプションを入力できる
- 投稿時に公開・非公開を選べる
- 写真ファイルはアプリ内の専用フォルダに保存する
- 投稿日時と投稿者を記録する
- 写真を選択していない場合は投稿できず、入力エラーを表示する

### 3.4 投稿一覧

- 公開投稿を新しい順に表示する
- 写真を中心にしたグリッド表示にする
- 各投稿で少なくとも写真、投稿者名、短いキャプションを確認できる
- 投稿を選ぶと投稿詳細を開ける
- 自分の非公開投稿は、自分だけが確認できる場所に表示する

### 3.5 投稿詳細

- 写真、投稿者名、キャプション、投稿日時を表示する
- 公開投稿はログイン中のユーザーが閲覧できる
- 非公開投稿は投稿者本人だけが閲覧できる

### 3.6 いいね

- ログインユーザーは公開投稿にいいねを付けられる
- 同じユーザーが同じ投稿へ複数回いいねできない
- 付けたいいねを取り消せる
- 投稿詳細でいいね数を表示する

### 3.7 コメント

- ログインユーザーは公開投稿に短いコメントを投稿できる
- コメントには投稿者と投稿日時を記録する
- 投稿詳細でコメント一覧を表示する
- 空のコメントは投稿できない

## 4. 余裕があれば追加する機能

必須機能が動作してから、必要に応じて追加します。

- 自分の投稿を編集・削除する機能
- 自分が書いたコメントを削除する機能
- 一覧にいいね数とコメント数を表示する機能
- 写真のファイルサイズ・形式の入力チェックを強化する機能

検索機能とユーザーフォロー機能は今回の対象外です。

## 5. 非機能要件

### 5.1 使いやすさ

- 初学者向けの小規模アプリとして、画面数と入力項目を増やしすぎない
- 入力に問題がある場合は、何を直せばよいか分かるメッセージを表示する
- スマートフォンでも写真一覧を見やすいグリッドにする

### 5.2 データ管理

- 開発中は SQLite を使用し、Peewee でデータを管理する
- 写真本体はデータベースではなくファイルとして保存し、データベースには保存先のパスを記録する
- データベースのモデル定義とテーブル作成処理を分かりやすく分ける

### 5.3 セキュリティ

- パスワードはハッシュ化して保存する
- アップロードできるファイル形式を画像形式に限定する
- 保存時のファイル名は、元の名前をそのまま使わず重複しにくい名前にする
- ログイン必須の画面・操作は、未ログイン時にログイン画面へ案内する
- 他人の非公開投稿をURLで直接開こうとしても表示しない

### 5.4 開発・動作環境

- Python、Flask、Peewee を使用する
- ローカル開発環境で動作確認できる構成にする
- 写真の保存先フォルダは設定としてまとめ、作成漏れがないようにする

## 6. 実装時に注意すべきこと

### 6.1 データの関係

- `User`、`Post`、`Like`、`Comment` の4つを基本モデルとする
- `Post` は1人の `User` に属する
- `Like` は「ユーザー」と「投稿」の組み合わせを保存する。ユーザーIDと投稿IDの組み合わせを一意にして、重複いいねを防ぐ
- `Comment` は1人の `User` と1件の `Post` に属する

### 6.2 公開範囲の判定

- 投稿一覧では公開投稿だけを基本として取得する
- 自分の非公開投稿を表示する処理は、公開投稿の一覧とは分けて考える
- 投稿詳細、いいね、コメントの各処理で、対象投稿を閲覧・操作できるか必ず確認する

### 6.3 画像アップロード

- フォームに `multipart/form-data` を指定する
- ファイル未選択、許可していない拡張子、同名ファイルの上書きをそれぞれ扱う
- 開発中に写真を削除してもデータベースだけが残る場合があるため、エラー表示を用意する
- 本番公開をする場合は、アプリ内フォルダ保存からクラウドストレージへの移行を検討する

### 6.4 段階的な実装

まず「登録・ログイン・写真投稿・公開投稿一覧」までを完成させます。その後、投稿詳細、非公開投稿の確認、いいね、コメントの順で追加します。各段階で、未ログイン時の制御と他人の非公開投稿が見えないことを確認します。
