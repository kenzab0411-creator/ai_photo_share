# 実装タスク

各タスクは、前のタスクが動作確認できてから進める。仕様の判断に迷った場合は `ai_context.md` を優先する。

## 1. アプリの土台

- `app.py` を作り、Flaskアプリを起動できるようにする。
- `instance/app.db` とプロジェクト直下の `uploads/` を設定値として定義し、起動時に必要なフォルダを作成する。
- 環境変数から `SECRET_KEY` を読み込む。
- Flask-Session、Flask-Login、Flask-WTFを初期化する。
- セッションはブラウザ終了時に終了する設定にする。

完了条件: トップページへアクセスでき、秘密情報をPythonコードへ直書きしていない。

## 2. ユーザーと認証

- `User` モデルと `users` テーブルを作る。
- 登録フォームを作り、ユーザー名の重複、未入力、パスワード確認を検証する。
- パスワードをハッシュ化して保存する。
- ログイン、ログアウト、ログイン必須の共通処理を作る。

完了条件: 新規登録、ログイン、ログアウトができ、未ログインで保護された画面を開くとログイン画面へ移動する。

## 3. 投稿モデルと画像アップロード

- `Post` モデルと `posts` テーブルを作る。
- 投稿作成フォームを作る。項目は画像、任意キャプション、公開範囲。
- JPEG・PNG・WebPかつ5MB以下だけを受け付ける。
- Pillowで画像として開けることを確認する。
- 元ファイル名をそのまま使わず、一意な保存ファイル名を生成し、プロジェクト直下の `uploads/` に保存する。

完了条件: ログインユーザーが公開・非公開の写真投稿を作成でき、不正なファイルは保存されない。

## 4. 投稿の閲覧と公開範囲

- 公開投稿を新しい順のグリッドで表示する。
- 投稿詳細で写真、投稿者、キャプション、日時、公開範囲を表示する。
- ログイン中は `/?visibility=private` で自分の非公開投稿だけを表示する。
- 他人の非公開投稿詳細には404を返す。

完了条件: 未ログインでも公開投稿を閲覧でき、他人の非公開投稿はURLを直接指定しても見えない。

## 5. 投稿の編集・削除

- 投稿者本人だけに編集・削除への導線を表示する。
- 編集ではキャプションと公開範囲だけを更新し、画像は変更しない。
- 削除確認画面を作り、`POST` で削除する。
- 投稿レコードを削除する際、対応する `uploads/` 内の画像も削除する。

完了条件: 他人の編集・削除は403となり、自分の投稿は編集・削除できる。

## 6. いいね

- `Like` モデルと `likes` テーブルを作る。
- `user_id` と `post_id` の複合ユニーク制約で重複いいねを防ぐ。
- 公開投稿だけに、ログインユーザーがいいねの追加・取り消しをできるようにする。
- 投稿詳細にいいね数と、現在のユーザーのいいね状態を表示する。

完了条件: 同じユーザーが同じ投稿へ複数回いいねできず、非公開投稿には操作できない。

## 7. コメント

- `Comment` モデルと `comments` テーブルを作る。
- 公開投稿だけに、ログインユーザーが空でないコメントを投稿できるようにする。
- 投稿詳細にコメント本文、投稿者、投稿日時を表示する。

完了条件: 空コメント・未ログイン・非公開投稿へのコメントを拒否し、正常なコメントだけが表示される。

## 8. 最終確認

- 全てのPOSTフォームにCSRFトークンがあることを確認する。
- 登録、ログイン、投稿、編集、削除、いいね、コメントの入力エラーを画面に表示する。
- 公開・非公開の権限確認を、一覧だけでなく詳細と更新操作でも確認する。
- `.env`、SQLite DB、セッション保存先、`uploads/` がGit管理対象外であることを確認する。
